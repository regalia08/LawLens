# test 평가셋 (`eval/test_questions.jsonl`) 작성 기록

## 왜 따로 만들었나

`eval/questions.jsonl`(63문항)은 개발 중 검색기·답변을 비교할 때마다 오답을 보며 쓴 셋이라 **dev**로만 쓴다.
그 셋을 둘로 나눠도 test는 이미 본 데이터가 되므로, test는 새로 만들었다.

**운영 규칙**: 튜닝과 선택(검색 k, 모델 비교 등)은 dev 점수로만 한다. test는 최종 후보를 정한 뒤에만 측정한다.

## 만든 방법

1. 이 프로젝트를 모르는 별도 LLM 대화에서 아래 프롬프트로 질문만 생성 (기존 평가셋·시스템 약점은 보여 주지 않음).
2. 프로젝트 작성자가 생성된 목록을 직접 검토·수정.
3. 정답 조문은 생성한 LLM의 답을 쓰지 않고, 조문 원문과 대조해 붙임.
4. dev와 중복되는 문항 제거: 임베딩(bge-m3) 유사도로 후보를 찾고, **같은 조항·같은 결론이면 중복**으로 판정.
   같은 조문이라도 묻는 사실이나 결론이 다르면 유지.

### 생성 프롬프트 (범위 안 50 + 범위 밖 10)

```
너는 한국의 다양한 노동자와 소상공인 사업주가 실제로 궁금해할 만한 질문을 만드는 역할이다.
이 질문들은 "근로기준법 조문 안내 챗봇"을 평가하는 데 쓰인다. 질문만 만들고 답이나 조문 번호는 쓰지 마라.

[질문자]
알바생, 신입·경력 직장인, 계약직, 임신 중이거나 육아 중인 근로자, 고등학생, 팀장급 관리자,
직원 몇 명을 둔 가게 사장님 등 다양한 사람을 고르게 섞어라.

[범위 안 질문 50개]
근로기준법(시행령·시행규칙 포함) 조문만 읽으면 답이 정해지는 질문이어야 한다.
판례나 개별 사정을 따져야 답할 수 있는 질문은 넣지 마라.
주제는 아래에서 고르게 섞어라.
- 근로계약과 근로조건 명시, 계약서
- 임금 지급 방법, 시기, 체불, 퇴사 후 정산
- 근로시간, 연장근로, 휴게시간
- 휴일, 연차휴가
- 연장·야간·휴일 근로 가산임금
- 해고 제한, 해고 예고, 해고 통지, 부당해고 구제
- 임산부, 육아 중인 근로자, 18세 미만 근로자 보호
- 직장 내 괴롭힘
- 취업규칙과 징계
- 업무상 재해 보상
- 사업장 규모에 따른 적용 범위
- 기숙사
- 근로감독과 신고
말투는 다음 비율로 섞어라.
- 60%: 일상어 (예: "잘렸어요", "월급", "알바")
- 20%: 법률 용어가 섞인 질문
- 10%: 조문 번호를 직접 묻는 질문 (예: "근로기준법 제○조가 무슨 내용이에요?")
- 10%: 자기 상황을 2~3문장으로 길게 설명한 뒤 묻는 질문
질문 하나에는 쟁점 하나만 담아라. 숫자(일수, 시간, 퍼센트)를 묻는 질문, 예외나 조건을 묻는 질문을 골고루 넣어라.

[범위 밖 질문 10개]
근로기준법 챗봇이 답하면 안 되는 질문이다. 아래 유형을 섞어라.
- 다른 노동 관련 법에서 답을 찾아야 하는 질문 (최저임금 액수, 퇴직금 계산, 실업급여, 산재보험 신청, 육아휴직 기간, 노동조합 등)
- 소송 결과 예측이나 자기 사건에 대한 법적 판단 요청
- 판례나 행정해석을 묻는 질문
- 고소장, 내용증명 같은 문서 작성 요청
- 노동법과 무관한 질문

[규칙]
- 60개 질문끼리 내용이 겹치지 않게 하라. 같은 상황을 말만 바꾼 질문은 하나만 남겨라.
- 실제 사람이 검색창이나 상담 게시판에 쓸 법한 자연스러운 문장으로 써라.
- 아래 형식의 번호 목록으로만 출력하라. 답, 조문 번호, 해설은 쓰지 마라.

## 범위 안
1. 질문
...
50. 질문

## 범위 밖
51. 질문
...
60. 질문
```

### 추가 생성 프롬프트 (범위 밖 10, 기존과 겹치는 유형 제외)

전세 보증금, 전세자금 대출 서류

## 판단 메모 (범위 안 유지)

- **t09, t34**: 4명 이하 사업장 적용 규정은 시행령 별표 1에 있는데 별표는 인덱스 밖이다. 정답은 제11조, 시행령 제7조. 알려진 한계를 드러내는 문항.
- **t29**: 토요일이 휴일인지는 행정해석 영역이지만, "법정 휴일(제55조)이 아니면 휴일근로 가산 대상이 아니다"까지는 조문으로 답할 수 있다.
- **t48**: 근로조건 일방 변경의 허용 여부는 판례 영역. 조문으로는 정당한 이유 없는 전직 금지(제23조)와 변경 시 명시(제17조)까지 안내 가능.
- **t18**: 질문의 전제가 틀렸다 (제74조 제5항은 시간외근로 금지, 태아검진은 제74조의2). 전제 오류 처리를 보는 문항으로 유지. 정답은 제74조의2.

## 판단 메모 (범위 밖)

- **t63**: 성희롱 조치를 남녀고용평등법 기준으로 직접 묻는다. 정답은 거절이며, 근로기준법 제76조의3(직장 내 괴롭힘 조치)으로
  답하면 거절 실패로 집계한다. 경계 문항이라 결과를 볼 때 따로 확인한다.
